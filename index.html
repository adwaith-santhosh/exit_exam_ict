Enterprise Annual Revenue Predictor

A lightweight web front-end to generate revenue predictions for an enterprise using a trained regression model. Provide a few company metrics and get an instant estimate.

  • Trained model uses company and financial features.
  • Handles categorical fields via one-hot encoding.
  • Fast inference with precomputed scaler.
